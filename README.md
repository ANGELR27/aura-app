# Aura — Red Social Privada 🌸

Una red social privada y de aprendizaje compartido, con diseño glassmorphism premium.

## ✨ Características

- 🔐 **Sistema de usuarios** completo con registro, login y perfiles
- 🪟 **Diseño Glassmorphism** con múltiples niveles de transparencia
- 💬 **Comentarios** en publicaciones con avatares
- 🔔 **Notificaciones** en tiempo real
- 📸 **Subida de fotos** desde galería/cámara
- 🎯 **Metas y hábitos** con tracking de progreso
- 📖 **Pasaje bíblico** diario
- 🔥 **Racha de días** activos
- 📱 **Responsive** — funciona en móvil y desktop

## 🚀 Ejecutar

```bash
npx serve -p 3000
```

Luego abre [http://localhost:3000](http://localhost:3000)
